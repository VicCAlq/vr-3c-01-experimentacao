# Relatório de experimentação

## Impressões do grupo sobre a jogabilidade
```Markdown
- Interação a partir do tempo, ao invés de botões.
- É necessário movimentar a câmera para analisar e visualizar a sala.
- Os controles são fáceis e práticos, tornando o jogo simples de se entender.
```
## Impressões do grupo sobre as limitações
```Markdown
- Movimentação da câmera lenta para locomoção do personagem
- Fases não tão complicadas com gráficos agradáveis.
- A movimentação contínua lenta, o que acaba se tornando entediante.
```
## Possibilidades pensadas pelo grupo sobre mecânicas de jogo
```Markdown
- Carregamento de interação mais rápida
- Mais objetos interagivéis
```
## O que o grupo considera ser possível em jogos AR/VR que não funcionam em jogos normais
```Markdown
- Muitos botões
- Interação com os itens/objetos
- Imersão espacial com movimentação simulando a câmera
- Interação baseada em tempo e observação
```
## O que o grupo considera ser possível em jogos normais que não funcionariam em jogos AR/VR
```Markdown
- Controles variados
- Interface complexa com múltiplas informações na tela
- Movimentação rápida e ações simultâneas sem risco de motion sickness
- Cutscenes com mudanças bruscas de câmera
```
